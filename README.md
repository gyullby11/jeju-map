# 내 제주 지도 — 설정 가이드

찜해 둔 장소로 날짜별 여행 코스를 자동으로 짜 주는 웹앱입니다. 파일은 `index.html` 하나이고, GitHub Pages에 올려서 폰으로 열어 씁니다.

---

## 1. GitHub Pages에 올리기 (10분)

1. GitHub에 로그인 → 오른쪽 위 **+ → New repository**
2. Repository name: `jeju-map` (원하는 이름 가능) → **Public** → **Create repository**
3. **uploading an existing file** 링크 클릭 → `index.html`을 끌어다 놓기 → **Commit changes**
4. 저장소의 **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** / **/(root)** → **Save**
5. 1~2분 뒤 새로고침하면 주소가 나와요:
   `https://gyullby11.github.io/jeju-map/`

> 카카오에 등록할 도메인은 경로를 뺀 **`https://gyullby11.github.io`** 입니다.

---

## 2. 카카오 JavaScript 키 발급 (10분)

1. https://developers.kakao.com 접속 → 카카오 계정으로 로그인
   (처음이면 개발자 등록 약관 동의)
2. 위쪽 메뉴 **앱** (또는 내 애플리케이션) → **앱 추가하기 / 애플리케이션 추가하기**
   - 앱 이름: `내 제주 지도`
   - 회사명: 본인 이름
   - 카테고리: 여행 → 저장
3. 만든 앱에 들어가서 **카카오맵 → 사용 설정 → 상태를 ON**
   - ⚠️ 이게 꺼져 있으면 키가 있어도 지도가 안 떠요 (2024년 12월부터 필수)
   - 무료 쿼터는 **내 계정에서 처음으로 카카오맵을 켠 앱**에만 주어져요. 이미 다른 앱에서 켠 적이 있으면 그 앱의 키를 쓰는 게 편합니다.
4. **앱 → 플랫폼 키 → JavaScript 키**
   - 키 값을 복사 (REST API 키 ❌, 네이티브 앱 키 ❌)
   - 같은 화면의 **JavaScript SDK 도메인**에 아래 주소 등록
     - `https://gyullby11.github.io`
     - (내 PC에서 테스트할 거면) `http://localhost:8080`
5. 앱 열기 → ⚙️ **설정** → 카카오 JavaScript 키 붙여넣기 → **저장**
   → 자동 새로고침 후 "✅ 카카오 연결됨"이 뜨면 완료

> 콘솔 메뉴 이름은 카카오가 가끔 바꿔요. 못 찾으면 앱 설정에서 "플랫폼 키", "카카오맵"을 찾으면 됩니다.

### 연결이 안 될 때
| 증상 | 확인할 것 |
|---|---|
| ❌ 카카오 연결 실패 | JavaScript 키가 맞는지 (REST 키 아님) |
| 지도가 회색 / 안 뜸 | 카카오맵 사용 설정 ON인지 |
| 콘솔에 domain 오류 | JavaScript SDK 도메인에 `https://gyullby11.github.io` 정확히 (끝에 `/` 없이) |
| 방금 바꿨는데 안 됨 | 5분 정도 기다렸다가 새로고침 |

## 3. OpenAI 키 (선택)

코스는 AI 없이도 만들어져요. "✨ AI로 순서 다듬기" 버튼을 쓰려면:

1. https://platform.openai.com/api-keys → **Create new secret key**
2. ⚙️ 설정 → OpenAI API 키에 붙여넣기 → 저장
3. 모델은 기본 `gpt-4o-mini` (다른 모델 이름으로 바꿔도 됨)

> 키는 **그 기기의 브라우저에만** 저장돼요. 코드나 GitHub에는 올라가지 않지만, 브라우저에서 OpenAI를 직접 호출하는 방식이라 **본인 폰/PC에서만** 쓰세요. 다른 사람과 링크를 공유할 거면 이 기능은 나중에 FastAPI 서버로 옮기는 게 안전해요.
> OpenAI 대시보드에서 월 사용 한도(Usage limits)를 걸어두면 안심입니다.

## 4. 우리 가족 일정 불러오기

`우리가족-제주-2026-10.json`에 항공편 3개, 여행자 6명, 숙소 2곳(날짜별), 렌터카가 들어 있어요.

1. 이 JSON 파일을 폰에 저장 (카톡 나에게 보내기 등)
2. 앱 ⚙️ 설정 → **JSON 불러오기** → 파일 선택
3. 🧳 여행 만들기에서 내용 확인 → **AI 코스 만들기**

- ⚠️ **JSON 파일은 GitHub에 올리지 마세요.** 공개 저장소라 누구나 볼 수 있어요. 올리는 건 `index.html` 하나만요.
- 도어락 비밀번호, 전화번호, 생년월일, 예약번호는 파일에 넣지 않았어요.
- 두 숙소 위치는 **대략값**이에요. 카카오 연결 후 🗺 내 지도 → 숙소 **편집** → **주소로 좌표 찾기**로 한 번 고쳐 주세요. (성산스테이윤슬은 에어비앤비 예약 확정 메일에 나오는 주소로)
- 성산스테이윤슬 입실/퇴실 시간은 15:00/11:00으로 넣어 뒀어요. 예약 확인 후 고쳐 주세요.

## 5. 사용 순서

1. **🗺 내 지도** — 장소 검색 → ❤️ 저장. 숙소도 검색해서 저장(카테고리가 🏨 숙소로 자동 분류).
   - 편집에서: 머무는 시간, 영업시간, 휴무 요일, 👶 아이와 갈 곳, ⭐ 꼭 넣기
   - 검색에 안 나오는 숙소는 **직접 입력하기 → 주소로 좌표 찾기**
   - **🕘 영업시간 자동 인식**: 검색해서 ❤️ 저장하면 바로 아래에 붙여넣기 칸이 떠요
     ① "카카오맵에서 영업시간 보기" → ② 영업시간 부분 길게 눌러 복사 → ③ "📋 클립보드에서 붙여넣기" → ④ **자동 인식**
     요일별 시간, 브레이크타임, 라스트오더, 매주·매월 n째주·특정일 휴무까지 채워져요. 나중에 편집 화면에서도 돼요.
     (카카오 API는 영업시간을 주지 않고, 가게 페이지를 앱이 자동으로 긁어 오는 것도 카카오가 막아 둬서 이 방식이에요.
      OpenAI 키가 있으면 못 읽는 형식은 AI가 대신 읽어요)
   - 저장할 때 **메모**를 같이 쓸 수 있어요 (검색 결과 아래 칸 / 직접 입력 / 편집). 코스에도 💬로 보여요
   - **📅 이 날 꼭 넣기**: 편집에서 날짜를 고르면 그날 코스에 최우선으로 들어가요. 코스 화면의 "📅 이 날 고정" 버튼, "못 넣은 곳" 목록의 날짜 선택으로도 돼요
2. **🧳 여행 만들기**
   - 📅 기본: 날짜, 하루 시작/끝, 저녁 포함 여부
   - 👥 여행자: 이름 + 만 나이 (만 12세 이하가 있으면 아이 규칙 자동)
   - ✈️ 항공편: 가는 편/오는 편, 날짜·시간, 탑승자. 일부만 먼저 떠나면 자동으로 "공항 배웅"이 들어감
   - 🏨 숙소 일정: 숙소별 체크인·체크아웃 날짜와 입실·퇴실 시간
   - 🚗 렌터카: 업체·차종, 인수·반납 시간, 셔틀·수속 시간(분)
3. **🧭 코스** — DAY별 동선, 이동시간, 길찾기 링크
   - 🔄 다른 코스 만들기 / 장소 빼기 / 꼭 넣기 ⭐ / 카카오맵
   - 📝 하루 메모 + 항목마다 메모 (비행기·렌터카·장소 모두). 코스를 다시 짜도 메모는 남아요

처음 열면 **제주 예시 30곳**이 들어 있어요(좌표는 대략값). 실제 여행 전에는 ⚙️ 설정 → 예시 지우기 후 카카오 검색으로 직접 저장하세요.

### 데이터 옮기기
장소는 브라우저에 저장돼요. PC에서 저장하고 폰에서 쓰려면 ⚙️ 설정 → **JSON 백업** → 폰에서 **JSON 복원**.

## 6. 코스 엔진 동작 방식

| 단계 | 하는 일 |
|---|---|
| 1. 후보 추림 | 저장한 곳 중 숙소·뺀 곳 제외 |
| 1-1. 고정 일정 | 날마다 비행기 도착·렌터카 인수·공항 배웅·숙소 이동·반납·탑승 시간을 먼저 박아 두고 그 사이만 채움 |
| 2. 거리 계산 | 좌표 직선거리 × 1.3(도로 보정) ÷ 거리별 평균속도(시내 30 · 중거리 40 · 장거리 48km/h) + 주차 5분 |
| 3. 지역 묶기 | k-means로 여행 일수만큼 권역 분리. 그날 출발점·경유지·도착점에 가까운 권역을 배정 (예: 마지막 날 성산→공항이면 동북부) |
| 4. 규칙 배치 | 하루씩 가까운 곳부터 채우되: 요일별 영업시간·휴무일 제외, 브레이크타임엔 도착하지 않게(식당은 브레이크 30분 전까지 입장), 라스트오더 이후 제외, 식당은 점심 11:30~14:00(저녁 옵션 17:30~19:30), 카페는 점심 뒤, 아이 관광지 3연속 금지, 휴무·영업시간 제외, 하루 끝 시간 안에 숙소 복귀, ⭐ 꼭 넣기 우선 |
| 5. AI 보정 | 순서만 다듬게 하고, 결과를 다시 규칙으로 검사해서 더 나빠진 날은 원래 순서 유지 |

이동시간은 추정치예요. 정확한 시간은 각 구간의 **길찾기** 링크(카카오맵)로 확인하세요.
